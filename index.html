        👆 Cara Menggunakan Login Fingerprint & Face ID

        Sistem ini menggunakan standar keamanan WebAuthn / Passkeys (FIDO2) asli dari browser dan perangkat Anda (bukan simulasi kamera palsu):

        1. Masuk ke akun Anda menggunakan Username/Email dan Password terlebih dahulu.
        2. Klik tombol 🔑 Passkey di bagian atas atau buka menu Pengaturan > Daftarkan Passkey Perangkat Ini.
        3. Konfirmasi menggunakan sensor sidik jari (Touch ID / Android Biometric / Windows Hello Fingerprint) atau pengenalan wajah (Face ID / Windows Hello Face) pada perangkat Anda.
        4. Saat login berikutnya, cukup klik tombol Login Fingerprint atau Login Face ID di halaman login.

        📥 Cara Import & Export Data Karyawan (Excel & PDF)

        1. Buka menu Data Karyawan pada sidebar kiri.
        2. Klik 📥 Import Excel/CSV lalu unduh template CSV/Excel yang tersedia atau unggah file `.csv` / `.xlsx` Anda.
        3. Untuk mengunduh laporan, klik 📊 Export Excel untuk format spreadsheet atau 📄 Export PDF untuk laporan siap cetak.

        💳 Keamanan Data Penggajian & Backup Database

        1. Data penggajian dan Slip Gaji dilindungi oleh Role-Based Access Control (RBAC) — hanya dapat dibuka oleh Admin/HR berwenang dan karyawan pemilik slip tersebut.
        2. Pemilik / Direktur (Super Admin) dapat mengunduh cadangan penuh database MySQL kapan saja melalui tombol 💾 Backup Database (.JSON) di halaman Pengaturan.
